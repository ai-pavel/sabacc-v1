# Sabacc Tournament (2005)

The original browser Sabacc card game set in the Star Wars universe,
written in 2005 by Revan (idea + code) and Darth Favourite (graphics).
You play against CPU opponents, trying to collect a hand worth up to 23
points; rules and FAQ (in Russian) are in `Правила.txt` and `FAQ.txt`.

Play online: https://ai-pavel.github.io/sabacc-v1/

An anniversary remake for modern browsers lives in
[sabacc-v2](https://github.com/ai-pavel/sabacc-v2) — play it at
https://ai-pavel.github.io/sabacc-v2/.
